# Phase 29 — reference-led character consistency

Directions has a separate Character reference workflow. Use a generated sprite as character master, upload one, or copy the Reference tab/front view. Keep one clean full-body reference per character and optionally describe distinctive details. Choose the art style and reference-capable checkpoint. Every requested unique view uses the same master rather than chaining generated angles. Reference prompt preserves features, proportions, costume, accessories and illustration style while asking for a single neutral full-body view. Qwen uses its existing reference conditioning; Neta uses initial-latent image-to-image and SDXL uses IP-Adapter. No new model or downloads. One image per request, sequential views, stop after the current view. Fixed seed reused for a set; individual Regen requests use a fresh seed. Lock accepted slots against replacement; unlock to edit or clear. Master, view locks and set seed persist with the project. Original template workflow retained.

Pixel output 32–128 square, optional exact low-colour master palette, nearest-neighbour alignment. HD directions use 256 square full colour (existing direction rig limit); common baseline at 94% and height target 86%, wide silhouettes fit width. Automatic rig is approximate and should be adjusted manually. Existing westward mirror rules remain: asymmetric details can be flipped. This is prompt/reference consistency, not deterministic identity recognition, multi-image conditioning or 3D reconstruction. Qwen/Neta may fail to turn the figure or reproduce details. Background removal is border keying, not segmentation. HD direction rendering has an aggregate 48-million-frame-pixel budget and smooth export filtering. Full GPU/browser tests pending. Tile and terrain unchanged.
