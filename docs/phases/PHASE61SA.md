# Phase 61S-A — Full-frame Animation Studio foundation

Independent workspace for complete PNG frames with reference artwork, motion description, common canvas/pivot, FPS, looping, reorder/remove/undo, and project/archive persistence. Select canvas dimensions before importing frames; no automatic alignment or resizing is performed. Existing skeletal tools remain unchanged. AI video generation, extraction, alignment, interpolation and exports follow later. CPU regression tests added; desktop acceptance pending.
