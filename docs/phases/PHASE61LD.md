# Phase 61L-D — Edge decontamination and alpha refinement

Use Refine current preview after automatic or manual alpha cleanup. Alpha cutoff removes faint partial-alpha pixels adjacent to transparency, not opaque pixels or interior partial-alpha pixels. Default hard pixel color preservation leaves surviving RGBA untouched. For HD halo correction disable hard color preservation, select the original matte color and adjust halo strength (0–100). Estimated matte inversion changes only surviving partial-alpha boundary RGB, retaining alpha; it is not semantic and can miscorrect already-unmatted colors. Auto matte selection skips color correction. No resizing, dilation of the silhouette or extra model. Full-erasure guard, undo and non-destructive preview remain available. Tests added for cutoff, hard edges, matte correction, unknown matte, full-erasure and API. CPU CI and real desktop acceptance pending. Opaque halos are not addressed by this pass. 61M follows 61L; Windows packaging remains on hold.
