# Phase 61L-C — Magic wand, erase and restore

In the Alpha Cleanup dialog, run automatic cleanup first, then select a manual tool. Magic wand removes a four-connected region matching the clicked RGBA within tolerance. Smart eraser uses the color and opacity sampled at stroke start; the unrestricted eraser removes pixels within a circular radius. Restore copies original source pixels into the preview. Dragging interpolates dabs in source coordinates; eight preview snapshots support undo. Reset restores the original, Cancel discards the session, Apply commits the current candidate unless fully transparent. Automatic Preview always recomputes from the original and replaces manual edits (undo can restore the previous preview). No model or new dependency. Canvas decoding/encoding may round partially transparent RGB values; byte-exact original RGBA preservation through browser PNG round trips is not guaranteed. The pure JS buffer helpers have regression coverage; CI and real desktop interaction remain pending. Next: 61L-D edge refinement. 61M exact-fit layers follow 61L; Phase 62 packaging remains on hold.
