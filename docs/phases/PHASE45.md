# Phase 45 — Animation retargeting between characters

Custom rig > Custom animation timeline > Animation retargeting. Open the source character, export current motion bundle (JSON containing validated custom profile and real source pixel dimensions, no sprite pixels). Open destination character and fit its skeleton, then import source bundle without replacing destination. Plain custom skeleton JSON with timeline is accepted too; enter actual source width/height (defaults 256 square until corrected). Up to 300 KB import. Auto mapping uses exact stable ID first, then unique normalized display-name/ID matches among unused destination bones. Edit one-to-one mapping; unmapped bones are permitted and unmapped animation tracks reported. Parent mismatch warnings flag incomplete/non-equivalent hierarchy. Source rotation curves copied as local rotations, preserving frame indices, curves, FPS and loop. Mapped unkeyed source fallback rotations become constant tracks when different from destination manual pose. Destination geometry, source pixels, weights and manual pose retained. Unmapped destination bones keep manual base rotations. One timeline per profile, so apply replaces old timeline and IK chains after confirmation. 512-key budget remains.

Optional two-bone IK transfer requires both controlled bones mapped and destination parent connection matches. Limb mode maps canvas-space target offset from rest upper joint by source/destination limb-length ratio and rest-axis rotation in pixel coordinates. Canvas mode keeps normalized target coordinates. Same transform applied to target keys and fixed contacts, preserving contact ranges; bounds violations skip chain with warning. Destination target reachability checked over all clip frames; report missed endpoints, locked misses and max residual. No guaranteed exact world-space motion, automatic semantic inference, root-motion correction or multi-character retargeting of incompatible skeleton topology. Geometry preview compares solved source and destination at selected frame without GPU inference. Apply only current preview; source/destination changes invalidate it. Render actual frames using normal timeline controls. Accepted AI cleanup PNGs never copied; destination cleanup becomes stale when fingerprint changes. Destination projects persist resulting timeline and IK. Motion bundle can be exported again. No new models.

Regression tests cover name suggestions, unchanged destination rest/skin, curve/timing transfer, limb and canvas contact scaling, reachability, incomplete mapping, duplicate destination rejection, actual destination weighted render and project persistence. JS syntax and IDs checked. CPU CI and interactive device validation pending.
