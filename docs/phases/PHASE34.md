# Phase 34 — Modular soft deformation and secondary motion

In Modular, select a non-body layer. Layer deformation has three modes: Rigid (original Phase 33 behavior), Soft garment joints (Auto split attachment required), and Spring secondary motion (single attachment bone or root required). Existing recipes default to rigid. Soft garment uses existing two-bone mesh interpolation on elbow/knee pairs; softness 0 retains hard partitions, higher values widen blending. Torso and other regions remain rigid. Hair sway, cape flutter, tail sway and soft garment presets set useful starting parameters, not automatic identification. Spring layers use a separately simulated chain from an anchor selected within visible layer bounds; normalized X/Y apply after scale, flip, offset and clipping to canvas. The anchor is snapped toward visible pixels, chain axis estimated toward the far end. Adjust anchor for side-facing/long assets. Segments 1–6; flutter 0–2, stiffness 0.4–2 and damping 0.1–0.9. The existing loop warmup and motion-driven wind are reused. Tiny/degenerate layers fall back to rigid. Each layer has independent settings and simulation, no new GPU models.

Use Preview modular motion to review; Save project or export ZIP recipe to persist each layer's settings. Normal composite PNG remains unchanged by motion settings. Rig profile remains reusable across clothing and hair swaps. Standard clip export uses the same rendering path as preview. Body softness remains a separate control. Bounds: 32 million frame pixels, 32 million retained supersampled surface pixels, 8 million supersampled canvas pixels when deformable layers are active. Hide unused layers, lower canvas or reduce frame count if a clip is rejected.

This is approximate 2D two-bone skinning and segmented spring motion, not cloth simulation with collision or true multi-bone weighting across all joints. Extreme bends may fold, overlap or show seams. Long hair/capes may clip outside the padded canvas. No independent layer animation sheets, custom modular keyframes or per-pixel weight paint yet. Existing flattened animation remains unchanged. Regression tests added; full CPU suite and live browser verification pending.
