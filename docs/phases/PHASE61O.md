# Phase 61O — Lightweight WebP image export

An Image download format selector above the workspaces offers PNG (default) and lossless WebP. Applies to standalone image downloads, including Generate results, editor selections, portraits, revision downloads, character masters, mannequin bases, modular source/registered/composite assets, custom poses and map images. Existing 1x and 8x options use nearest-neighbor scaling; WebP encoding uses Pillow with lossless and exact RGBA, preserves dimensions and transparent pixels, and checks the encoded input and output pixel budget. PNG remains the default and project/engine export packs (PNG sheets and frames, GIF, JSON, Godot, Unity, Tiled) are unchanged; no animated WebP or WebP atlas pack in this small phase. Selection persists through saved project settings; old projects default to PNG. WebP is not always smaller than optimized PNG. Encoder availability depends on the local Pillow build; failures are reported rather than mislabeled. CPU and JS regressions added; CI and desktop download acceptance pending. Phase 62 packaging stays on hold.
