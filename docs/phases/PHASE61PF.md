# Phase 61P-F — VFX timeline and keyframes

Up to 32 keys per effect, indexed relative to active start. Each key contains X/Y position offset, scale multiplier, rotation offset, opacity multiplier and RGB tint (white preserves base colors). Outgoing interpolation is linear, smoothstep or hold; values hold before the first and after the last key. Keys layer on procedural movement and all stages including impacts; projectile heading follows combined path. Artwork tint follows the same RGB multiplier. Radius stays within 4–128; standalone canvas uses conservative largest local cell plus sampled offset bounds and existing resource budgets. Scene bounds can clip as before. Studio and Scenes support add/update/delete/clear, key selection and current frame selection. Existing recipes default to no keys. Keys retain relative timing when shifting start or exporting an effect. Scene shortening prunes out-of-range keys after confirmation; direct effect edits reject shortening until keys are removed. No independent per-property tracks or editable Bezier handles. CPU regression coverage added; desktop acceptance pending. Public automatic validation enabled.
