# Phase 61P-C — Projectile motion paths

Four procedural presets (fireball, energy bolt, ice shard, magic orb) share a deterministic translation from the effect origin to signed X/Y displacement, with straight, parabolic arc, ease-in or ease-out timing. Positive arc height rises on screen. The active frame interval defines travel duration; speed controls artwork pulse, not arrival time. Direction follows path tangent plus rotation. Trail/glow controls apply; slash sweep/thickness are unused for projectiles. Fixed standalone cells cover all sampled positions, bounded by existing preview limits. Scene effects use world-space displacement from the current effect anchor; actor attachment follows the actor, not a sampled launch position. Scene bounds may crop traveling effects deliberately. PNG/GIF exports reuse the scene compositor; recipes remain version 1 and receive defaults. CPU regressions added; not run locally. Public-only automatic validation restored, manual dispatch retained. Desktop acceptance and CI pending. Impact chaining is Phase 61P-D; no AI inference or packaging.
