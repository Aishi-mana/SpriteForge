# Phase 61K-F — Character Studio and Modular integration

AI editing is available for approved artwork, approved sprites, saved mannequin body bases, selected modular layers and current rendered composites. Studio assets expose editing entry points; the artwork and modular workspaces expose direct buttons. A per-source staged result supports repeated instruction editing and session history before explicitly applying to an approved artwork, sprite or saved body base. Existing approval confirmations and project save behavior are reused. Modular outputs are added as a new whole-image layer after confirmation; adding a body hides prior body layers but retains other layers. Existing rig sources are not replaced automatically. Review alignment and refit rigs where needed. Staged candidates are session-only, one per source kind, cleared on project load and discarded when the source changes or an approved revision is applied. Source identity checks reject stale revisions. Edited composites are flattened images, not automatically separated equipment. Sampling defaults follow current workspace settings and may require adjustment. Real desktop and GPU testing remain outstanding. Phase 62 remains on hold.
