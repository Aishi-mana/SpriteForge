# Phase 61C — Expressions and gestures

In Portrait > Expressions & gestures, choose emotion, gesture and optional custom description. Approve a master first, select a compatible reference model and use half/full framing for non-neutral gestures. Results can be saved/exported via the framed portrait controls. Whole-image regeneration is not pixel-identical and reference identity is approximate. Original masked pixel expression editing remains available. HD/rectangular masked editing is not yet implemented. GPU verification remains outstanding.
