# Phase 61K-E — Edit history, undo and comparison

Generated result cards now expose Edit history. Accepted AI edits retain the original and subsequent revision snapshots with image and output metadata. Restore, undo, redo, compare and download previous revisions without generating again. New edits after undo discard subsequent revisions. The editor also offers a first-original comparison alongside the current source and candidate. History is session-only per result object (WeakMap); it is not saved into projects. Up to 12 revisions and a 24-million-character encoded image budget are retained, dropping oldest intermediate revisions first. The original and current image are always kept even if those two exceed the budget. External modifications reset stale AI history. Restoring a revision invalidates template rig metadata; independent animation assets are not automatically modified. Actual desktop interaction and GPU editing quality remain unverified. Phase 62 remains on hold.
