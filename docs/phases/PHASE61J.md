# Phase 61J — Alpha cleanup

Shared flat-color cleanup detects exterior background and sufficiently large, nearly exact enclosed color pockets. HD character generation uses the requested background key; pixel removal uses dominant border color. Existing transparent images remain unchanged by automatic finishing; result cards offer explicit reprocessing. Choose Alpha cleanup, original background, mode, tolerance and soft edges, then Preview or click pockets in Manual mode. Reset returns to original; Apply updates result for subsequent export or rigging. Choose a contrasting background when generating. Color keying is not semantic segmentation; exact matching foreground can be removed. Manual mode avoids automatic selection. The CPU algorithm does not reconstruct hidden foreground or guarantee complete halo removal. Desktop visual verification remains outstanding.
