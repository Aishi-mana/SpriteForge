# Phase 64C — Character reference replacement

Direct Animation Editor > Replace character. Choose original frame range, replacement PNG or approved sprite, optional instruction, guide type and size, and alpha method. Installed Wan Fun Control is required. The original motion guide is generated automatically; the requested video duration covers all selected timestamps, with tail hold for supported frame counts. Generate at 20 control steps, extract untrimmed frames, reverse aspect-ratio padding and sample back to the original frame count and FPS. Reject short candidates, locked ranges and invalid artwork budgets. Compare staged changes before Apply; source document and unrelated frames remain untouched until application. The raw candidate video is session-only. The original reference metadata is retained in this phase. No exact pose, identity, proportion or contact guarantee; no paired actor replacement yet. BiRefNet requires local setup. CPU tests added; GPU and desktop verification pending.
