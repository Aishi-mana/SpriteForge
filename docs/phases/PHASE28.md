# Phase 28 — character model compatibility

Checkpoint selector shows architecture and readiness. LoRA options are labelled Family match, Unverified or Incompatible for the selected checkpoint. Incompatible choices are disabled and cleared when switching model; backend also rejects known mismatches. Header metadata and tensor signatures are heuristics, not proof of shape/training compatibility.

Text-to-image routes: SDXL and SD 1.5 single-file checkpoints; complete local Diffusers pipeline folders for SDXL, SD 1.5, Lumina 2 (NetaYume), FLUX.1, SD3/3.5 and Qwen-Image. New architectures are experimental until GPU-tested. Flow architectures keep native scheduler. Sequential CPU offload reduces VRAM, but large models may still exceed RAM/VRAM. Existing reference, ControlNet and inpaint workflows require SDXL.

NetaYume: put a complete Diffusers version (with model_index.json, transformer, tokenizer, scheduler, VAE and text encoder) under models/checkpoints/NetaYume. A recognized Lumina single-file checkpoint can also be attempted with a complete local Lumina 2 base pipeline in checkpoints/Lumina2-base; this loads the transformer using Diffusers single-file conversion and uses the base's other components. Comfy all-in-one files may not convert; use a compatible Diffusers folder instead. No automatic model download. FLUX/Qwen/SD3 raw single files are not supported by this implementation. Use the local folder version.

Update dependencies (diffusers>=0.36; newer may be necessary for particular model versions) before relaunch. Start with one variation, 512–768 pixels, then raise resolution if memory permits. No verified GPU generation yet. No changes to earlier phases. Tile and terrain follow-ups deferred.


## Installed-runtime integration (Mana parity)

The uploaded Mana setup/standalone/reference-art guides describe successful local configurations on an RTX 5070 Laptop GPU (8 GB VRAM, 32 GB system RAM). This patch uses the same installed Comfy tensor libraries in an owned one-shot Python subprocess; no server, custom-node discovery, model duplication or downloads. Source provenance: ManaAI-CV-2 scripts/image_job.py blob dc4a726eb9136f636c48a3fb922ea873ea7fc97f and scripts/qwen_image.py blob fdccad4059257237ca4cb875412c7093c8c7cbc0. Source app untouched. The exact documented checkpoint names select the standalone route; other architecture routes above remain available.

Set the SpriteForge models directory to the existing ComfyUI-Shared/models directory, not its checkpoints subfolder. NetaYumev35_pretrained_all_in_one.safetensors is discovered in checkpoints. Qwen-Rapid-AIO-SFW-v23.safetensors is also discovered in diffusion_models. The Qwen worker needs text_encoders/qwen_2.5_vl_7b_fp8_scaled.safetensors and vae/qwen_image_vae.safetensors. The documented loras/modern-anime.safetensors is selected at strength 1 when available and classified as a family match; it is optional, not silently substituted for a missing file. Other LoRA choices remain subject to architecture validation; arbitrary adapter loading is experimental.

The runtime defaults to the existing Comfy Desktop installation under LOCALAPPDATA (ComfyUI-Installs/ComfyUI/ComfyUI and its .venv/Scripts/python.exe). If installed elsewhere, set SPRITEFORGE_COMFY_ROOT and SPRITEFORGE_COMFY_PYTHON before launching SpriteForge. Readiness checks files without loading weights and lists missing dependencies. Do not upgrade or reinstall the working Comfy environment automatically.

Neta: normal auto-offloading (never forced lowvram or gpu-only), GPU text encoding, Euler/normal, 20 steps, CFG 4, 1024 square default. The all-in-one checkpoint supplies encoder and VAE. Image references use the VAE initial latent, with reference strength mapped inversely to denoise 0.2–0.8. Qwen: installed dynamic memory allocator initialization, unload the visual encoder before loading diffusion, reference-latent conditioning with index_timestep_zero, shift 3.1, pre-CFGNorm 1.25, res_multistep/simple, 4 steps, CFG 1. Use a conservative 768-square SpriteForge starting size, not Mana's 1280x720 scene canvas; selectable up to 1024. Qwen image references are optional, fresh whole-image generation and do not use Neta denoise or SDXL IP-Adapter. No automatic Mana avatar attachment. Both routes start with one variation.

The engine releases its cached Diffusers pipeline before starting the child and serializes image work with its existing generation lock. The child exits after each image, retaining original PNG, settings, progress and logs under ignored local-image-jobs/. Queue cancellation stops only the owned local worker (on Windows taskkill by owned PID/tree); other apps are not stopped. SDXL queue cancellation retains the existing discard behavior. Qwen may still exceed memory when other local models are active; no measured SpriteForge memory cap or host-memory guarantee. Keep the installed runtime revision unchanged; internal allocator APIs can differ. Model files are read-only. Existing SDXL ControlNet, masked edits, joint cleanup and Phase 26 inpaint remain SDXL-only. On Reference tab turn off Use skeleton pose for the standalone models.

The guides report accepted Neta generation around three minutes and Qwen reference jobs around one minute on the other app, not measured SpriteForge performance. No native GPU tests have been run in SpriteForge. Tests here cover file discovery/readiness, request routing and size/seed bounds; live image quality, memory use, optional LoRA application and cancellation remain to verify.
