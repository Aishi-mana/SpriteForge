# Phase 61M-B — Body landmarks and placement masks

Fixed-canvas mode now estimates head, shoulder, waist, leg and foot bands from the actual visible body alpha, in recipe canvas coordinates. Category fitting uses the relevant band union with padding. A nonrectangular row-envelope guide is returned as a separate PNG, along with landmarks and candidate visible-pixel spill statistics. Guides are advisory: no clipping or pixel deletion. Accessory/other categories use a broad body region. Legacy fitting remains unchanged. This is a geometric silhouette heuristic using fractional vertical bands, not semantic landmark detection, a skeleton pose estimator, or proof of exact anatomical fit. Unusual poses, hair already on the base, extreme proportions and disconnected shapes may need manual adjustment. Guide is not yet fed to a diffusion model. Tests cover asymmetric silhouettes, category separation, mask dimensions, non-destructive spill reporting and empty body. CI and real-model/desktop verification pending.
