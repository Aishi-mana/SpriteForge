# Phase 61P-A — Standalone VFX Studio and effect library

New VFX Studio workspace (tab 17) reuses Phase 47 renderer and existing atlas exporter, with eight built-in presets: sword slash, impact flash, sparks, fire, smoke, lightning, aura and magic circle. Edit name, color, radius, opacity, frame count (2–32), FPS, active frame range, rotation, speed, seed, particles, gravity, emission, pixel/smooth sampling and loop. Render and scrub fixed transparent cells; play without a character. Save up to 40 named recipes in local browser storage; JSON import/export is portable. Current recipe and library are session/browser-local rather than part of project bundles; export recipes for backup. Current frame download follows global PNG/WebP preference. Atlas export retains PNG, optional individual PNGs/GIF and standard engine metadata. Add a validated effect to current scene at current frame, centered; reject insufficient scene duration instead of silently truncating. No new projectile or explosion presets yet; B advanced slashes, C moving projectiles, D impact/explosion chaining, E AI artwork, F timeline, G combat integration, H validation/export polish. Automatic CPU Actions disabled on main by user request (manual dispatch retained); tests added, not run in CI or locally here. Desktop acceptance pending. Phase 62 packaging on hold.
