# Phase 63I — World integration, validation and usability

Open World Studio > Paired interaction playtest, or use Preview on current map from Paired Preview. Choose world origin (defaults to spawn) and scale, then start. Existing map validation, effective collision masks and layer depth metadata are reused. Both actors are drawn independently from their source clips with sampled timing, per-frame transforms, flip, scale and depth. The pair is sorted as a group against map depth layers; foreground artwork covers both. Staged playback supports release at a loop boundary. Collision/walkable checks warn on each actor pivot footprint; no movement solver or automatic repositioning. World and original character documents are not modified. Pair validation reports simultaneous visibility and existing scene limits. Map/pair edits stop the running preview. Preview placement is session-only.
