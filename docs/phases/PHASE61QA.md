# Phase 61Q-A — World Studio foundation

Dedicated World Studio (tab 18), independent of the session-only Phase 55 tile painter. Default quarter-view 1280×720 modern anime environment, smooth display; HD-2D, painted, pixel and custom style labels, top-down/side/isometric metadata (no projection-specific gameplay yet). Free-positioned PNG raster layers, roles for background, ground/detail, objects, foliage, foreground, shadows, lighting and collision/walkable/occlusion masks. Layers are bottom-to-top; move, reorder, lock, hide, opacity, undo; zoom/scroll and spawn marker. Masks use alpha coverage, must share map dimensions and origin; debug overlays never appear in normal PNG export. World data is versioned and validated server-side; optional field in existing project.json and portable project archive, standalone world JSON. Bounds: 64–3072 per axis, 6M canvas pixels, 24 layers, 24M total source pixels, 48MB encoded. Existing tile workbench untouched. No AI, tile painting in this workspace, actual collision/navigation, depth sorting or playtest yet. CPU regressions added; validation pending.

Roadmap: B structured AI blockout with common layout and separated visuals; C character-derived style matching; D gameplay masks and depth hints; E manual polish and regional regeneration; F playtest actors and VFX; subsequent map transitions, NPCs, tile integration and engine export based on acceptance. Phase 61R system UI assets planned, Phase 62 packaging held.
