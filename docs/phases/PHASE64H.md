# Phase 64H — Original/edited comparison, undo and export

Direct Animation Editor now includes side-by-side, adjustable overlay and visible pixel difference comparison, changed-frame navigation, staged redo and restore-all. Difference uses premultiplied RGB and alpha, ignoring invisible RGB. History is session-only, bounded to eight entries and a 48 MB unique staged-image budget. Export a checkpoint containing staged changes and SHA-256 fingerprint of the exact source JSON; resume against the same document with validation and explicit confirmation. Checkpoints do not contain original artwork or raw video. Export original or edited candidate independently as PNG atlas ZIP, PNG frames ZIP, animated WebP ZIP or editable animation JSON without applying. Paired replacement candidates can export independent sprite packages before acceptance. Animated WebP encoders may coalesce identical frames; use PNG/atlas for exact indexing. Existing MP4 downloads remain separate. Checkpoint hashing requires a secure browser context (localhost). Regression assertions added; Node checks, CPU CI and desktop acceptance pending at authoring.
