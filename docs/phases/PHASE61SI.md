# Phase 61S-I — Combat animation metadata

Combat motion presets and per-frame phase, event, label, rectangular hitbox, effect anchor and root displacement in canvas pixels. Metadata persists by direction and remaps on reorder/removal/interpolation. Extraction resets metadata. Edit selected frame and preview saved hitbox/anchor overlays. This is authored metadata, not a combat runtime; combo labels do not execute combos. Desktop/GPU acceptance pending.
