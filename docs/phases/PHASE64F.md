# Phase 64F — Selective paired character replacement

Paired Preview > Replace one character — preserve interaction. Select A or B, import a new reference PNG or use approved artwork, choose guide and alpha method, then generate via installed experimental Wan Fun Control. Alternatively import an exact-count replacement PNG sequence. Original selected actor source frames provide the motion guide; restoration uses original source timestamps and canvas. Backend validates count, dimensions, nonempty alpha and shared scene budgets. Side-by-side original/candidate composite playback uses the existing scene clock. Accept changes only the selected clip; original pivot, FPS, offsets, transforms, depth overrides, anchors, partner and stage settings remain. One-step undo restores the original clip. Cancellation discards results, not active GPU inference. Source scene changes invalidate candidate. No anatomical contact guarantee, automatic re-alignment or hidden-pixel reconstruction. CPU regression cases added; desktop, GPU and CI validation pending.
