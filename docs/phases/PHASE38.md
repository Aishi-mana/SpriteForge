# Phase 38 — Character model and asset library manager

New Library tab stores reusable local snapshots across projects. From Modular save the complete character recipe (including hidden outfit alternatives, layer transforms, deformation, occlusion and saved rig), the selected asset, or an explicitly saved body rig. Give it a name, tags and optional notes. Search names, categories, tags and notes; filter by type; inspect thumbnails; delete snapshots independently. Character snapshots load a validated copy after confirmation. Asset copies insert into the current recipe, retain the original source PNG, category and compatible attachment/motion settings. Keep placement optionally reuses offsets, scale and flip only for a matching canvas size. Manual canvas-space weight paint and body occlusion are reset on asset import for review; complete character snapshots preserve them. A new body hides earlier body alternatives and invalidates the saved rig. Rig presets only apply when the transformed body/canvas fingerprint matches exactly. The library never modifies saved projects until the user saves the active recipe.

Library data lives in character-library/ under the SpriteForge root, ignored by Git. Each entry has a UUID directory, JSON metadata and payload, and small PNG thumbnail. Writes publish an atomic directory after successful validation. 300 entries, 1 GB payload total, 26 MB per snapshot (existing modular layer limits also apply). Search reads metadata only. Back up the directory separately if moving machines. Deleting library copies does not delete project copies or source model files.

The model manager lists installed checkpoints using the existing architecture detection and local runtime readiness checks. Inspect paths, single-file sizes, backend, capabilities, runtime file presence and missing dependencies. Qwen Rapid checkpoints share the installed text encoder/VAE and Comfy core paths; NetaYume uses the existing all-in-one route. Both registered Qwen filenames remain available. LoRA rows filter family matches, unverified adapters or all installed adapters; incompatible choices are disabled. Selecting a checkpoint uses the existing model defaults, then applies the explicitly chosen adapter or none. Rescan refreshes installed options, keeps the current selection where possible and does not load any weights. Fixed scan edge case for Qwen diffusion_models without a checkpoints folder.

This is a local file-presence and header inspection manager, not a downloader, installer, dependency version validator, model converter or GPU benchmark. Folder model size is not recursively calculated. Family matching does not prove adapter compatibility, and installed runtime files do not establish successful inference. No additional AI or GPU load for library operations. Regression tests added for snapshot round trips, search, matching rig validation, safe IDs and deletion isolation. Browser and full CPU suite validation pending.
