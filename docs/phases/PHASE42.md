# Phase 42 — Advanced animation timeline

In Custom rig, load and fit a source and choose rigid or weighted skinning. Create animation clip. One editable clip per custom profile, 2–32 frames, FPS 1–60, loop or one-shot. Track grid rows represent bones and columns represent integer frames starting at zero. Select a cell or scrub. Set/update rotation and outgoing interpolation, capture the selected bone or all bones from the existing manual pose, duplicate selected key to a destination, or delete it. Shortening the clip asks before dropping out-of-range keys. Up to 512 keys. Each track holds its first/last key outside its interval; unkeyed bones retain manual rotation. Linear interpolates signed angles directly, ease uses smoothstep, stepped holds until next key. No automatic shortest-angle wrapping or loop seam blending. Duplicate start/end poses as needed for a seamless loop. Changing timeline does not edit manual pose. Deleting bones removes corresponding tracks.

Render current frame for inspection or render full timeline for playback, scrubbing and adjacent onion skins (green previous / pink next). Playback uses one clock interval, stops on edits and leaving the tab; one-shots stop on final frame. Onion skins use rendered frames only, including loop neighbors; no interpolation of unrendered images. Editing geometry, source, weights, pose, padding or timeline invalidates cached renders. Full render reuses weighted mesh binding across frames. Preview budget 12 million frame pixels, export 32 million, existing pose surface and cumulative rigid work limits also apply. Large weighted clips can still take time on CPU. No GPU or model inference required.

Export animation spritesheet uses existing exporter with fixed untrimmed frame canvas, shared rest root-head pivot, FPS and loop tag, PNG atlas and Godot/Unity metadata; optional GIF and individual PNG frames. Exported sprites are baked, not live custom-rig skeletons. Root-head pivot is not necessarily feet. The generic exporter may overwrite a same-named clip folder; choose a distinct clip name when needed. Save project or export skeleton JSON to retain tracks, weights, and rig; the source image remains separate from JSON. No multiple editable clips per profile, position/scale tracks, custom bezier handles, IK, timeline retargeting or independent modular layer animation in this phase. Existing standard Animate and Modular systems are unchanged.

Regression tests cover track validation, easing/linear/step, nonmutating pose evaluation, reused binding, consistent frame dimensions, single-frame equality, export and project persistence. UI syntax and literal IDs checked; full CI and live browser validation pending.
