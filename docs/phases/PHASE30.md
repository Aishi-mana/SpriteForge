# Phase 30 — Character identity and appearance locking

In Directions choose Character reference and pin an approved full-body master. Use Appearance locks to preserve face, eyes, hair, body proportions, outfit/footwear, accessories, art style, pose and expression independently. Default locks preserve the first seven; pose/expression remain editable. Lock all, unlock all and restore defaults are shortcuts. Direction generation uses the selected locks while still asking for its camera angle; the old template path and accepted direction locks remain unchanged.

Choose a variation target (one feature or Custom), describe the change, and Generate separate variation. The named target is temporarily removed from the preserve list, not from the saved lock profile. Custom changes require at least one unlocked feature. The prompt puts the requested change first and retains the other explicitly selected features. Qwen uses native reference conditioning, NetaYume uses image-to-image, SDXL uses IP-Adapter. Existing reference influence, model-specific sampling and memory policies apply; Qwen ignores reference influence. One candidate at a time, no automatic retry or additional model load. Pixel palette locking is optional only for pose/expression changes; other targets may need new colors. HD candidates use 256–1024 output (not limited to the 256px direction canvas).

Compare the separate candidate against the unchanged master in the main area. Save candidate to the project gallery, use it as a pose reference or animate it. No automatic replacement of master or approved direction slots. Latest candidate and metadata are saved separately in project data; save to gallery before generating another candidate if you want to keep it. Feature locks and change description persist with the project. Older projects use default locks. If the master is replaced, existing candidate is marked as generated from an earlier master.

Locks are prompt/reference guidance, not deterministic feature-level or pixel-exact locks. No automatic facial recognition, semantic mask, segmentation, garment layer extraction or identity adapter is added. Pose/expression/outfit changes can still alter other features, especially with strong redraw settings. Visually approve candidates; use manual edits or later masked workflows for precise preservation. GPU and browser validation pending; tile/terrain untouched.
