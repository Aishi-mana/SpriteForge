# Phase 61Q-D — Gameplay masks & depth hints

Deterministic CPU suggestions from current raster artwork, not AI semantic segmentation. Walkable alpha coverage is the union of visible ground-detail/trail (default) or ground layers at an adjustable source threshold; subtract suggested collision. Props default to Y-sorted and solid ellipses based on bottom 12% of visible silhouette, avoiding canopy-wide collision; foreground layers default always in front and non-solid. Per-layer local anchor, radii, depth mode, solid and occludes are editable. Occlusion is the alpha silhouette above the contact area for sorted props or full foreground silhouette. Generated masks are map-sized binary-alpha PNG layers marked generated; rebuild only replaces generated masks, refuses locked generated masks, preserves imported/manual masks. Effective masks union alpha >=128 by role regardless of editor visibility/opacity; collision wins. No walkable mask means spawn walkability unverified. Source hash and presence of all three suggested roles detect stale suggestions; check/rebuild after visual edits. Blockout optionally generates masks (UI default on); existing API default off for compatibility. Layer and source budgets apply to all masks. Debug overlay filters and anchor/footprint visualization; visual export unchanged. Depth hints are data for future actor sorting, not a change to normal layer compositing.
