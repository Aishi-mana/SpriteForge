# Phase 27 — soft joint deformation

Animate now has Soft joint deformation (0–100%). Start at 35–60%. Zero uses the existing rigid renderer. Each arm and leg with both upper and lower bone labels gets a textured two-bone mesh; vertex weights blend across the painted boundary. Elbows and knees bend with the mesh; other bones and painted cape/hair/tail keep the existing renderer and draw order. Missing pairs fall back to rigid. Pixel sprites use nearest sampling and the original palette/downsampling path. HD uses premultiplied-alpha bilinear sampling. CPU-only, no new dependencies.

Settings are stored per clip and included in preview, single/pack export and directional clips. Phase 25 custom keyframes can use the same renderer; Phase 26 image endpoints bypass it. Old projects default to zero. Softness is an approximate blend radius rather than a physical parameter. Very sharp bends may fold, shrink, stretch or self-overlap; this is not volume-preserving mesh skinning or full occlusion reconstruction. Inspect frames and adjust bone labels/softness. Memory budget is enforced on the supersampled canvas. Tests cover identity, bend, palette, alpha, fallback and integration. Full checkout/Windows visual verification pending.
