# Phase 61M-C — Qwen body-conditioned extraction

Opt into Qwen edit & extract in Modular with fixed canvas and a Qwen checkpoint. The existing guarded instruction editor dresses the visible body reference, maps output back to the original canvas and removes background. Difference extraction retains visible pixels whose RGBA differs beyond background tolerance or occupies previously clear pixels. No crop, fit or repositioning is applied to the extracted layer; original body remains untouched. Guide spill is reported, not clipped. Raw preview is the dressed edit, not the original model-sized output. The isolated layer, combined preview and body reference are separate. This is experimental pixel differencing, not semantic garment extraction: body drift can leak into the asset and same-color garment areas can be missed; review required. Existing isolated fitting remains available. Mocked tests added; CI, actual Qwen quality and desktop acceptance pending. Next 61M-D other backend support; packaging on hold.
