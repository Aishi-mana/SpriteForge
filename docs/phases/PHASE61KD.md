# Phase 61K-D — Editing presets

In AI edit reference, select a Quick editing preset, enter a description, and click Use preset. Ten operations cover outfit, armor, adding/removing equipment, wings, hair, recoloring, expressions, poses and featureless mannequin templates. Instructions remain editable. Presets suggest identity locks and regional mask guidance; replacing an existing instruction requires confirmation. Wings disable original-canvas preservation only when regional mode is off. Nothing is generated until Generate edit is pressed. Existing Qwen, Neta and SDXL adapters are unchanged. Presets do not perform automatic segmentation, equipment extraction or guarantee character identity; review the candidate. The mannequin preset is non-explicit and does not replace the deterministic CPU body-base tool. Real GPU and desktop verification remain outstanding. Phase 62 remains on hold.
