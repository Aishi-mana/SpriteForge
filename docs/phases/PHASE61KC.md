# Phase 61K-C — Identity preservation controls

AI edit reference now includes ten individually selectable feature locks and presets for outfit/general, equipment, hair, pose, recoloring, all and none. Default locks preserve face, eyes, hair color, hairstyle, body proportions, pose and art style. The user can uncheck features intended to change. All supported backends receive the same selected guidance; no active outfit profile is automatically injected. The API validates unique known lock keys, supports an explicit empty list and reports selected locks as prompt guidance. Regional masking remains the exact pixel preservation mechanism. Conflicting instructions and selected features may reduce adherence. These are not semantic masks or hard identity guarantees. Real GPU and desktop testing remain outstanding. Phase 62 remains on hold.
