# Phase 61M-F — Asset cleanup, alignment and workspace integration

Generated Modular candidates can be cleaned with the existing Alpha Cleanup dialog before acceptance. Offset, scale, opacity, horizontal flip and front/behind/stack depth can be adjusted and explicitly previewed using the CPU compositor. The review endpoint validates the recipe budget, rejects empty or entirely off-canvas assets and recalculates guide statistics on the transformed layer. Original recipe/body and original generated candidate remain unchanged until explicit approval; reset restores the generated candidate. A registered PNG export bakes reviewed transforms into a transparent full-canvas image; ordinary asset PNG remains the source layer. Pending edits block approval until previewed. Partially clipped assets remain possible and require visual inspection. Manual alignment is numeric, not drag-and-drop; browser canvas partial-alpha rounding remains.
