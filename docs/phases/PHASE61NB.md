# Phase 61N-B — Generate prompt transparency

Generate has an expandable Final prompt preview. Inspect current prompts calls the CPU-only preview endpoint; no model loading or inference. It exposes style text, assembled positive and negative prompts, mode, checkpoint, LoRA weight and background. The engine uses the same prompt_pair helper for native and local-worker generation. Preview is a settings snapshot, not token-level inspection or proof that the backend honors every term; changing inputs requires inspection again. Copy is optional and depends on clipboard permission. Style presets remain rendering/proportion guidance only. Existing prompt semantics and model policies unchanged. CPU tests added, CI and desktop acceptance pending. Next 61N-C: 2–7-head presets in existing Art Style selector. Packaging on hold.
