# Phase 61S-B — Local AI video backend

Optional local LTXImageToVideoPipeline (Diffusers). Place a compatible complete Diffusers model snapshot under the configured models directory in video_models/<name>/, with model_index.json declaring LTXImageToVideoPipeline. Install compatible Diffusers, Accelerate, CUDA PyTorch and imageio-ffmpeg in the engine environment. See https://huggingface.co/docs/diffusers/api/pipelines/ltx_video. No automatic model downloads. CUDA and BF16 support required; CPU offload reduces GPU residency but RAM/VRAM requirements vary. Generate using reference and motion prompt; dimensions multiples of 32 and frames 8k+1. Preview/save MP4; discarding preview does not interrupt GPU execution. Opaque letterbox background; transparency extraction follows later. Mock tests only, real GPU acceptance pending.
