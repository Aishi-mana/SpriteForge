# Phase 53 — Character identity and consistency (initial)

In Directions > Character workflow > Reusable identity profiles, save a named snapshot of the current master reference, identity description, appearance locks and art style. Load another profile after confirmation; existing directional slots are preserved, so review their consistency. The profile list is device-local browser storage (up to 20 profiles, subject to storage quota); it is not a portable project file or a backup. Directional consistency review displays the master and required views with locked/review/missing indicators. It is a manual visual comparison, not an automatic similarity score. No new conditioning models, multi-reference inference or guaranteed identity preservation are introduced. Existing generation and project persistence remain unchanged. Interactive desktop testing remains required.
