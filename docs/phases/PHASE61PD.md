# Phase 61P-D — Explosion and impact chaining

Three standalone procedural bursts: explosion, shockwave and frost burst. Any projectile can optionally transition to one of these or the existing impact flash. The final reserved frames become the impact, immediately after the projectile reaches its exact endpoint; two or more flight frames required. Impact duration (1–30 frames), size (50–200%, capped at radius 128) and color are independent. The same recipe and scene compositor drive scrub/playback, scene insertion and fixed-canvas export. The impact remains at the endpoint relative to the current anchor, including moving actor attachments; there is no collision detection, arbitrary multi-stage chain or physics simulation. Old recipes retain no-impact behavior. Corrects 61P-C Scene path controls being in the Studio panel. CPU regression tests added; not run locally.
