# Phase 61R-F — HUDs and resource bars

Bind image, rectangle or text instances to HP, MP, stamina, XP, cooldown or custom values. Set maximum, value and direction; image and rectangle fills clip without distorting artwork. Text displays numeric values. Preview sliders and damage/heal buttons are transient; PNG export uses saved defaults. Existing portrait/frame artwork remains reusable. Timed cooldown animation, floating indicators and live world bindings are deferred. CPU/JS tests added; desktop acceptance pending.
