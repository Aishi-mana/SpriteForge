# Phase 37 — Advanced layer occlusion and manual bone weights

In Modular, choose a non-body layer and set Layer deformation to Manual two-bone weights. Choose two distinct bones (root, torso, head, upper/lower arms or legs). The default weight is uniform Bone A; Base B weight sets the uniform blend. Paint B influence with a radial brush, or paint weight zero toward A. Brush strokes blend smoothly at their edges; later stamps override earlier stamps proportionally. Orange/blue canvas overlay is an approximate guide. Undo removes the last stamp; Clear paint restores the base blend. Limit 192 stamps per layer, each stored in normalized rest-canvas coordinates; radius is a fraction of the longer canvas side. Source changes do not move painted weights: repaint after changing the source alignment, flip, scale or canvas. The actual renderer uses a bounded regular mesh with linear two-bone skinning. Only the selected two bones influence the whole layer. Auto garment segmentation, rigid attachments and spring chains remain separate options. The body continues to use its existing skeleton.

Animated layer depth can follow the existing stack or force a layer behind/in front of the body. Order within each depth group follows the recipe stack. Static composite and manifest draw order use the same depth override. Choose individual body bones that should cover a foreground layer, e.g. a forearm should appear in front of a shirt or held object. The renderer subtracts the selected moving body part alpha from the independently rendered layer. Masks are baked into that layer's animation sheet. Selected bones from a soft elbow/knee pair occlude the entire pair, because that pair is one rendered mesh. Masks only account for the current body rig, not other modular accessories, and are not dynamic collisions. Semitransparent edges can be approximate. Depth and occlusion are separate: behind-body layers already render behind all body parts. Static composite does not simulate moving bone masks.

Saved recipes/project data retain motion and occlusion settings; existing recipes keep default behavior. Layer export uses the same depth order and captures masked individual layers; runtime components use manifest z order. Re-export all clips from the same edited recipe after changing weights/depth/occlusion because its fingerprint changes. The existing flattened animation path is retained. No AI inference, no GPU models. Mesh resolution and retained surfaces are bounded by existing CPU memory budgets; selected occluder alpha surfaces count toward the budget. Full multi-bone weight maps, arbitrary per-pixel z-order, dynamic inter-layer occlusion, collision handling and live skeletal export remain future work. Regression tests added for two-bone paint, body masks, saved rig and exported ordering; browser and actual engine validation pending.
