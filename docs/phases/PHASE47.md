# Phase 47 — Visual effects, magic and particles

Scenes > Visual effects, magic & particles. Add magic circle, sword slash, impact flash, sparks, fire, smoke, lightning or aura. Up to 12 effect layers per scene. Effects are CPU procedural drawings, not AI-generated art or a GPU particle engine. Select kind when adding, edit name/color/radius (4–128 px), opacity, depth, rotation, speed, seed and active inclusive frame range. Sparks/fire/smoke use seeded particle samples (1–96), burst or continuous emission and gravity; aura uses a bounded particle count; other presets use animated geometry. Motion phase is normalized to each effect's active range; speed modifies preset motion, not global FPS. Fire/smoke rise vertically; rotation changes the particle spread, not a general emitter orientation. Pixel mode draws directly at native resolution; smooth mode draws 2x then downsamples. Seeded rendering is deterministic independent of scrub order. Effects composite with straight RGBA alpha, no additive/bloom shader. Effect z interleaves with actors; effects in front of actors at equal z, stable list order within effect layers. Free position uses scene coordinates. Attachment follows a visible actor's animated pivot and mirrors horizontal offset when flipped; scale, opacity and rotation do not inherit, and no live bone attachment. Deleting actor removes its attached effects after confirmation. Shortening scene clamps both actor and effect ranges. Duplicate/delete and timing track overview. Render current frame/full scene, same preview and export path; effects-only scenes supported. Scene JSON and project scene save persist recipes, old scenes get empty effect list. Standalone export selected effect to centered transparent cell (4*radius+8), active duration, scene FPS, fixed canvas, optional GIF/individual PNG and standard metadata. Requires 2+ active frames. Export is baked; no collision, dynamic lights, particle physics simulation or automatic spell behavior. Effect size/duration/count work budget limits CPU allocations. Regression tests cover all presets, determinism, scrub/full match, depth, attachment visibility, persistence and malformed inputs. JS syntax/IDs checked; CPU CI and live app validation pending.
