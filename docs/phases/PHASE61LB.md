# Phase 61L-B — Ground shadow removal

Alpha Cleanup now offers Ground shadow removal mode and independent shadow sensitivity (0–100, default 50). On opaque backgrounds it first runs the 61L-A exterior pass; on assets with substantial clear border it skips color-key cleanup. A CPU component heuristic identifies dark translucent or neutral/darker-key shallow horizontal regions near the bottom of the non-candidate foreground and adjacent to exterior transparency. Retained RGBA values remain unchanged; no model or new dependency is needed. Preview before applying; zero sensitivity disables the shadow pass, not the opaque background pass. Colored, steep, overlapping or same-color attached shadows may be missed; wide neutral garments or platforms near feet may be mistaken for shadows. This is not semantic segmentation. Manual erase/restore in 61L-C remains necessary. Regression tests cover translucent and opaque shadows, retained clothing and boots, zero strength and API counts. CI and desktop acceptance pending. 61M remains queued after 61L; Phase 62 packaging remains on hold.
