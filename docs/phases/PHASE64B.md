# Phase 64B — Motion and pose reference extraction

In Direct Animation Editor, choose an inclusive original frame range, then Extract original motion reference. Analyze motion produces per-frame source index, relative time, alpha bounds, centroid, centroid displacement, bottom edge and opaque-frame flags. Save JSON for reuse. Build an MP4 visual guide from original artwork, alpha silhouette or grayscale edges; preview, save or send to installed Wan Fun Control in advanced mode. Artwork guides use Canny; silhouette/edge guides use prepared control. Source canvas aspect ratio is retained with padding. Sampling uses original FPS, holds final selected pose if longer and truncates if shorter; Fit duration selects nearest supported 4n+1 count within 9–97 and 8–30 FPS. Guide dimensions divisible by 16, 24M pixel limit, existing source budgets. No interpolation, anatomical joint detection, optical flow or exact pose guarantee. Alpha geometry may be meaningless on opaque images. Handoff does not start generation or change the source document; choose replacement reference and prompt separately. Guide/report are session-only unless exported; subsequent phases integrate replacement directly.

CPU regression assertions added for measurements, range, sampling and rendered silhouette. Tests, MP4 playback, Fun Control GPU adherence and desktop acceptance pending at authoring.
