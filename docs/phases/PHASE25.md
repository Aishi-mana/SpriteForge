# Phase 25 — custom keyframes and reference-guided poses

Select custom in Animate. Load a source sprite, adjust its rest rig, then select custom. Capture start at 0%, end at 100%, optionally add intermediate keyframes. Use Restore source rig to return to the original bone assignment. Each saved keyframe can be edited or removed. Upload a start or end reference image to estimate joints with existing bounding-box autoplace; manually refine the pose. References are normalized to the source dimensions and do not supply artwork or reliably detect actual pose. All frames use source sprite artwork with eased rigid bone transforms. No AI image morphing or mesh skinning. Preview and single-clip Export use the same keyframes; project rig stores the timeline. Custom clips are not supported in Directions or multi-clip selection.
