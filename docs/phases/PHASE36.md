# Phase 36 — Runtime character assembly and equipment

Independent layer export now includes runtime/godot/SpriteForgeCharacter.gd, runtime/unity/SpriteForgeCharacter.cs and runtime/README.md. The manifest remains version 1 with an added character_id SHA-256 fingerprint of the normalized recipe (non-body visibility excluded). The fingerprint and exact exported layer ID set are checked when keeping equipment across clip switches. Export every clip with the same recipe and hidden alternatives included. Different FPS, padding and frame counts are supported through per-clip geometry. Re-export older Phase 35 bundles for persistent loadouts.

Each component creates one Sprite2D or SpriteRenderer per layer, positions all layers at the common pivot, uses one animation clock and frame index, and draws in manifest order. Loop and one-shot clips supported; one-shot completion signal/event. Play, pause and resume. Equip hides other layers in the selected category; explicit visibility allows stacked equipment; body protected. Save/load/reset equipment with a character fingerprint. Switch clips via explicit manifest paths; new recipe requires an intentional reset. Only one active clip retained after a successful switch; loading is synchronous and temporarily holds both texture sets. A failed file load releases candidate objects and retains current character. Godot uses res:// imported PNG textures where available; Unity desktop uses StreamingAssets or absolute local paths. Loadout files are engine-specific, stored in user:// or persistentDataPath by default. No AI dependency at runtime.

Setup instructions accompany each export. This is a baked-frame rendering component, not an inventory database, gameplay state machine, runtime skeletal animation or networked equipment system. Unity Android/WebGL streaming needs a separate loader. No real Godot or Unity runtime test has been performed; integration scripts require editor validation. Python regression tests cover fingerprint stability and bundled file presence, but are not executed here. Existing Phase 35 sheet and flattened exports remain compatible.
