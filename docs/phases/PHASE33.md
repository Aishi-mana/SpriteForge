# Phase 33 — Modular layer rigging and bone attachment

In Modular, select exactly one visible body layer. Every other visible layer has a bone attachment: root (whole-body movement), torso, head, left/right upper/lower arms and upper/lower legs, or Auto split across bones. Default hair attaches to head, outfits and footwear auto-split, accessories attach to torso (choose the appropriate hand/forearm for weapons). Layer order relative to body controls whether an asset draws behind or in front. The body is rendered by the existing skeleton and each asset is transformed independently using the same world matrices. No AI or additional GPU model required.

Load/edit body joints opens a draggable body-only joint canvas. Save body rig stores joints and a fingerprint of the transformed body/canvas in the modular recipe. Changing gear, visibility or layer order without changing the body preserves the saved skeleton. Changing the body, its position or canvas invalidates the profile; automatic joints are used until a new profile is saved. Reset body joints loads automatic placement for editing and saving. Project save and ZIP recipe/manifest preserve attachment settings and the body rig. No manual bone-pixel paint overrides in the modular joint editor.

Preview modular motion supports the 11 standard clips, count/fps/facing/near side/weapon arm/amplitude/padding/body softness. Export clip produces the existing sheet/atlas/export formats using current recipe and export settings. Flattened composite Animate remains available. Preview invalidates on layer edits. Pixel/HD rendering uses recipe sampling, and low-color pixel attachments extend the body palette instead of being forced into it. At most 32 million frame pixels and 32 million retained supersampled surface pixels; hide unused layers or reduce frames/size/padding if over budget.

This initial attachment implementation is rigid or nearest-bone segmented, not weighted garment skinning. Auto-split layers may have visible seams or imperfect overlap; layer order is coarse (before/after body), not automatic limb-level occlusion. Hair/cape secondary physics, independently rigged layer export, custom keyframes and reference-endpoint clips are not part of this modular renderer. Existing body soft-joint deformation is optional; clothing does not inherit soft mesh weights. Baked clothing remains baked. CPU regression tests added, browser/GPU validation pending.
