# Phase 61L-F — Workspace integration

Alpha Cleanup is available on generated results, artwork/sprite candidates before approval, approved master artwork, approved sprite, body base, selected modular layer and current modular composite. Approved sources use the existing staged review and revision history; applying cleanup to a stage does not approve it. Explicit approval, PNG export, add-as-layer and same-size selected-layer replacement are separate actions. Layer replacement retains offsets, category, scale, opacity, attachment and other settings, validates dimensions and library size, and refreshes composite/rig state. Review weights and animation after replacement. A composite cleanup is a flattened candidate, not per-layer extraction. Stale source guards and project cache reset are retained. Browser canvas rounding remains a limitation; desktop acceptance and CPU CI pending. Phase 61M follows 61L, Windows packaging on hold.
