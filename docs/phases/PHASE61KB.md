# Phase 61K-B — Regional masking and protected areas

In AI edit reference, expand Regional edit & protected areas and enable Edit painted regions only. Paint red on editable pixels, erase to protect, adjust brush size, clear, select all or invert. Regional mode fixes the original canvas dimensions. Generate and inspect before accepting. Qwen and Neta generate a whole-image candidate then composite only the binary editable region; SDXL additionally receives the transformed regional inpainting mask. Outside the mask, original RGBA bytes are retained exactly, including transparent RGB values. This does not guarantee registration or visual continuity inside the selection. For wings, reserve transparent space in the original canvas or use unmasked expanded editing. Hard binary boundaries may show seams.
