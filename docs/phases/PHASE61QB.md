# Phase 61Q-B — AI structured environment blockout

Prompt + World Studio style + editable per-role materials guide separate single-image generation passes on the selected local backend. A deterministic quarter-view plan provides a winding/straight trail or clearing, perspective-scaled props outside the trail at their anchors, foreground decorations and spawn. The background, ground surface and path are rendered as separate plates; path alpha derives from the common layout polygon, not semantic segmentation. Rock/tree/foreground art is keyed to transparency and reused as separate movable instances, with size and mirroring variation. Generation is sequential, displays pass status, and only replaces the prior map after all passes and validation succeed. Cancel stops between passes, not an active inference. Three-million-pixel AI canvas limit, 0–6 rocks/0–8 trees/0–2 foreground clusters. Project stores normalized blockout settings, not model seeds per role. Shared prompts and geometry improve consistency but cannot guarantee matching perspective or lighting; background keying may fail. No semantic decomposition of a single image, automatic gameplay masks, character style extraction or playtest. CPU synthetic regressions added; GPU and desktop validation pending.
