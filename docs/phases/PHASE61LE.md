# Phase 61L-E — Pixel preservation and protected regions

Paint protection or remove protection using the manual tool selector and source-pixel brush radius. Cyan overlay is separate from exported pixels; toggle visibility or clear the mask. Manual wand, erasers and restore skip protected pixels; wand traversal stops at protected pixels. Automatic cleanup and current-preview refinement accept an optional same-size black/white protection PNG and restore protected RGBA from that operation's input after processing. Protection does not constrain automatic segmentation traversal, and does not recover pixels erased before protection was painted. Undo snapshots include masks; reset clears protection. Masks are session-local. Browser canvas partial-alpha rounding still applies to manual edits. Tests cover mask painting, manual protection, API compositing and wrong dimensions. CI and desktop acceptance pending. Phase 61M follows 61L; Windows packaging stays on hold.
