# Phase 44 — AI-assisted animation cleanup

Custom rig > Custom animation timeline > AI-assisted frame cleanup. Render a clip or current frame, scrub to problem frame, open cleanup panel. Select an installed verified SDXL checkpoint compatible with the existing inpainting pipeline (optional compatible LoRA). Native Qwen/NetaYume reference runtimes do not support true masked inpainting and are excluded from this operation. No new model bundled; a compatible local SDXL checkpoint and existing Diffusers setup are needed, with any required pipeline config already available. Select 512/768/1024 inference canvas, default 768, strength .35, 20 steps, CFG 5, seed 0. Tune on device; actual VRAM and image quality not benchmarked. One frame per request; no multi-frame AI job queue or cancellation of active inference. No IP-Adapter dependency introduced.

Choose automatic joint discs on posed skeleton (including IK), manual rest-of-frame brush, or both. Brush coordinates refer to the padded rendered frame, not source geometry. Up to 128 stamps; radius 1–25% of longer side. Preview actual mask before generating. Backend rejects empty or >55%-canvas masks. By default alpha lock restricts edits to visible pixels and preserves all original alpha bytes. Optional silhouette repair derives alpha from contrast background chroma key and rejects excessive area changes; HD soft alpha can become binary inside mask when unlocked. Palette lock applies only to pixel frames with up to 96 original visible colors; otherwise reported skipped. Inpaint letterboxed frame, low-strength prompt guidance for same identity/pose/costume, resize back, copy only selected pixels. Outside-mask RGBA bytes remain exact. It is prompt/seed-based consistency guidance, not guaranteed identity or temporal consistency.

Review original/candidate/accepted PNG side by side. Accept, discard, restore original per frame, or clear accepted collection. Timeline playback/onion skin and exports use accepted PNGs only when enabled and fingerprint matches normalized source bytes, profile and padding. Original frame cache never overwritten. Rerender after editing to verify; stale corrections remain separately saved but cannot apply to a different clip. Export explicitly prompts before using originals when saved corrections cannot be verified. One accepted set per rig/timeline; up to 24 MB encoded PNG data, 32 frames; accepted images stored separately in project.json, not skeleton preset JSON. Candidates and brush masks are session-only. Existing standard humanoid AI cleanup unchanged.

CPU mock regression tests check exact outside-mask bytes and alpha, palette, actual model-space mask, single/full fingerprint, accepted replacement, stale or mismatched rejection and project persistence. JS syntax and literal IDs checked; CI pending. Real SDXL GPU inference and browser painting/review remain to be tested.
