# Phase 64D — Outfit, appearance and equipment editing

Direct Animation Editor > Appearance and equipment edits. Select a compatible installed Qwen, NetaYume or SDXL editor, use an existing edit preset or custom instruction, select the current frame or inclusive range, and choose original or staged inputs. Sequential edits share prompt and seed. Original frame count, canvas, timing and metadata are retained; locked ranges are rejected. Optional input alpha preservation copies source alpha and restores source RGB where the candidate is transparent. Disable for silhouette expansion, which remains limited to existing canvas. Batches are limited to 32 frames and source dimensions <=1024; every result must succeed and pass validation before staging. Cancellation discards batch results but cannot interrupt an active GPU request. Existing edits are retained on failure. Identity locks are prompt guidance, not pixel protection; equal seeds do not guarantee consistency. No new models or changes to standard Wan. Regression assertions added; desktop, GPU and CI validation pending.
