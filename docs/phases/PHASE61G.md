# Phase 61G — Character Studio

Open Character Studio from navigation or command search. The dashboard shows current project identity/outfit, master, expression base and expressions, approved sprite, linked rig and retained standard clips. Stage shortcuts open the existing tools. Linked asset previews can be downloaded; saved project gallery supports ID filtering and PNG download. Save and load use existing project persistence. The dashboard does not create a new asset database or independently classify gallery images. Framed HD portraits saved to the gallery are not automatically linked as expression bases. Generation and rigging retain existing limitations; GPU and interactive desktop verification remain pending. Phase 61H is intentionally on hold until validation and merge.
