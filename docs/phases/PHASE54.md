# Phase 54 — Animation clip library and transitions

Custom rig > Custom animation timeline > Saved animation clips: store up to 24 named timelines with IK chains, activate or delete them, and save the project to retain the library. Activation validates against the current skeleton; existing skeleton and skin stay unchanged. Store the current clip before switching. Accepted AI corrections are cleared on switching. Backend validates stored clips before saving. Names can group clips by prefix. Create transition to saved clip constructs a separate non-looping rotation-only timeline with eased interpolation from the last active frame to the first saved frame, at the active FPS, using 2–16 frames. Store it under a new name. IK contacts and cleanup are not carried over. Root translation and full motion graph blending are not implemented. Actual desktop testing remains outstanding.
