# Phase 65H — Import, export and library backup

Download full library ZIP or individual portable asset ZIP. Versioned manifest includes each file size and SHA-256; raw PNG/JSON/MP4 payloads and thumbnails retained. Restore validates member names, checksums, sizes, metadata, artwork, first video frame and relationship graph in staging before publishing. Existing IDs never overwritten; collisions remapped and internal links rewritten. Links to assets outside the archive are detached and counted rather than linked to unrelated local IDs. Existing quota applies to merged library; no destructive replace mode. ZIP uses stored files and disk-backed temporary output; maximum archive 1.1 GB. Restore rollback on ordinary publication failures, not a guarantee against process/power interruption. No models, projects, configuration or credentials included. Download through browser/WebView; large backup UI behavior needs desktop acceptance.

Acceptance: export full and individual archives, restore to empty and populated libraries, verify byte-identical payloads and relationships, reject malformed/oversized archives and ensure no partial assets. Regression coverage added for six kinds, collision remapping, external links, checksum/path/duplicate/missing members and capacity. CPU and desktop validation pending.
