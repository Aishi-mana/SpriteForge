# Phase 64E — Temporal consistency and flicker correction

Direct Animation Editor > Temporal consistency & flicker correction. Stage appearance edits or character replacement, choose at least three consecutive edited frames, then Analyze staged flicker or Stage conservative correction. The CPU compares original triplets to candidate triplets. Only source-stable opaque pixels with agreeing edited neighbors and isolated color outliers are eligible; optional alpha repair adjusts existing partial alpha only when source alpha and neighboring candidate colors/alpha agree. Strength, source motion tolerance, neighbor agreement, outlier threshold and maximum channel adjustment are configurable. No whole-frame blending, position changes or loop seam wrap. Locked centers, unchanged frames/neighbors and range endpoints are skipped. Results stage as one undoable operation; the original animation remains unchanged. Diagnostic counts are heuristics, not perceptual quality scores. Large pose changes, identity drift and missing pixels are not repaired.
