# Phase 64G — Direct video editing and sprite extraction

Direct Animation Editor > Direct video editing and sprite extraction. Import an MP4 or reuse the current generated video. Original bytes are kept separate; select start/end milliseconds and sampling FPS. CPU trim/resample and reverse produce silent MP4 candidates. Experimental AI regeneration uses a selected replacement reference, padded source motion guide and installed Wan Fun Control with Canny conditioning. This regenerates motion-guided video rather than editing exact original pixels. Guide frame count may hold the final pose to satisfy 4n+1. Preview and download source/candidate separately. Extract candidate frames using BiRefNet, chroma or keep-background, then stage into an existing selected range with source timing/canvas restoration; short results and locked ranges are rejected. No persistent asset storage yet (Phase 65). Source and candidates are session-only unless downloaded; opening requires an existing animation. Limits: 64 MB input, 120 sampled frames, 24M sampled pixels, 2048 source side, guide limits 97 frames/32 MB. Tests added for sampling and invalid inputs; actual MP4 encoding/playback, GPU generation and desktop acceptance pending.
